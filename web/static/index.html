核心功能 Features

📤

多格式智能加载

支持 PEC、Arbin、Neware(3种变体)、TVC、通用 CSV 共 6+ 种格式。AI 自动分析文件结构并映射列名，失败时自动回退到 LLM 智能加载，支持对话式校对。

⚖️

多实验对比分析

叠加曲线对比 (overlay)、电压差值分析 (delta)、性能指标表。自动计算容量保持率、库仑效率趋势、电压滞后等关键指标。

🔬

7 模式退化分解

NNLS 分解电压变化为 7 种退化模式：SEI 生长、Li 析出、正/负极活性物质损失、阻抗增长、扩散退化、电解液耗竭。量化各模式贡献占比。

📐

DOE 设计空间分析

自动检测 26 个 DOE 因子 (9 组)、模板/通用双模式。仪表盘总览、因子详情卡片、组合热力图、衰减影响桑基图、缺失组合推荐。

🔍

智能历史检索

基于设计向量+性能向量+退化向量的三维相似度搜索。支持相似搜索、对比搜索 (设计相似但退化不同)、结论关联。

📝

结论管理与验证

结构化结论存储，5 种状态流转 (active/confirmed/challenged/revised/retired)。AI 自动验证结论与证据的一致性。

分析流水线 Pipeline

  • 1数据加载 — 多格式自动检测 + LLM 智能加载 + 对话式校对。批量上传失败自动 AI 重试。
  • 2周期摘要 — 提取每圈放电容量、充电容量、库仑效率、内阻、容量保持率。
  • 3设计元数据 — 自动关联实验设计 YAML，或从电芯挂测表模板解析 26 个 DOE 因子。
  • 4退化模式分解 — 基准电压曲线 → ΔV(t) 计算 → NNLS 求解 7 模式系数 → 主导模式判定。
  • 5DOE 覆盖率分析 — 单因子覆盖率、组合覆盖率、缺失组合推荐、衰减影响相关性。
  • 6历史检索与对比 — 三维向量化 + 余弦相似度，支持相似/对比两种搜索模式。
  • 7结论闭环 — 结论 CRUD、AI 验证、状态流转，构建可追溯的知识库。
